Titos Restobar
Titos Restobar es un proyecto de software que simula la gestión de un restaurante. En este proyecto se aplican los siguientes conceptos y tecnologías clave:

Programación Orientada a Objetos (POO): El diseño del proyecto sigue principios de POO para crear un sistema modular y fácil de mantener.
Modelo Vista Controlador (MVC): La arquitectura del sistema está basada en el patrón MVC, separando la lógica de negocio, la interfaz de usuario y la gestión de los datos.
Diagrama de Entidad-Relación (DER): Se ha creado un diagrama de entidad-relación para el diseño y la estructuración de la base de datos.
Diagrama de Clases: El diseño del sistema está soportado por un diagrama de clases que representa las relaciones entre los objetos del dominio.
Tecnologías utilizadas
Lenguaje: Java
IDE: Apache NetBeans
Base de datos: MySQL
Este proyecto sirve como una demostración práctica de cómo aplicar los principios de diseño y patrones arquitectónicos en una aplicación real, utilizando Java como lenguaje principal y MySQL para la gestión de datos.
